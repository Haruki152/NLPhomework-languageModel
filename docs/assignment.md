# 课程题目整理

原始题目见 [assignment.pdf](assignment.pdf)。下面按实现与提交要求整理，题目表述以原 PDF 为准。

## 实验任务

搭建一个基于解码器的语言模型，结构类似 GPT，进行下词预测。

1. 实现因果多头自注意力。手写多头拆分、注意力计算、因果掩码和 softmax，不能直接调用 `MultiheadAttention`。
2. 实现归一化模块，参照 GPT。
3. 实现完整的解码器语言模型，包含词元嵌入、任选一种位置编码以及从隐藏维度到词表大小的输出映射。
4. 自己编写参数统计函数。数据集自选，可采用 BPE 或单词分词。
5. 在小模型上调试与训练，损失开始下降即可，不要求充分收敛。
6. 约 300M 参数的模型只做参数统计和推理演示。

题目中的“线性归一化”在本项目中按层归一化实现；“下词的注意力得分”按语言模型的词表 logits 理解，与内部注意力权重区分。

## 提交内容

- 带注释的完整 Python 源代码。
- 实验报告，包括模型超参数表、参数量结果、训练损失图、程序调试过程和字符串生成样例。

原题要求禁止直接粘贴 GPT 实现源码，也禁止组间复制。这里的核心计算按基础张量运算实现，算法与代码对应说明见实验报告。
